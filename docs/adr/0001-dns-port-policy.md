# ADR-0001：固定 DNS 重定向端口策略

- **状态**：已接受
- **日期**：2026-10-03

## 背景

模块提供 AdGuard Home DNS 过滤，可选提供 TLS/DoH。设备 iptables 规则将 DNS 请求重定向到 AdGuard Home 的 DNS 端口；HTTP/HTTPS 管理及服务端口属于独立配置，不应因 DNS 端口策略而变更。模块不应拥有或改写代理模块的配置。

## 决策

### DNS 重定向端口

`config.prop` 中的 `redir_port` 是固定 DNS 重定向端口配置，默认值为 `5591`。服务每次启动都读取并验证该值；缺失或无效时仅在运行时回退至 `5591`，不写回配置文件。AdGuard Home YAML 中的 DNS 端口与此值保持一致，不产生随机 DNS 端口。

### HTTP/HTTPS 与代理配置

DNS 端口策略不改变 AdGuard Home 的 HTTP 或 HTTPS 端口。模块不再支持代理配置管理：不读取代理订阅，不改写代理 YAML，也不同步代理 DNS 设置。代理模块的配置由用户自行管理。

## 范围与安全边界

本 ADR 定义固定 DNS 重定向端口及模块与代理配置的边界。TLS 证书、私钥、令牌及其他秘密均不提交到仓库，也不作为示例配置或文档附件保存；部署者应通过设备本地或受保护的配置机制提供它们。

## 后果

- DNS 重定向端口固定为 `redir_port`，无效配置回退至 `5591`；配置文件不会被服务启动改写。
- HTTP/HTTPS 端口不受 DNS 端口策略影响。
- 代理 YAML、订阅及代理 DNS 配置不由模块管理。
- 端口策略不会自动携带或生成任何证书、私钥或其他秘密。
